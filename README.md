# Inspiration Library ✦

A personal, minimalist Are.na / Pinterest style inspiration library where you can collect imagery, bookmarks, typography references, and notes into curated boards.

Built with **Next.js (App Router)**, **Better Auth**, and **Supabase PostgreSQL** via the native `pg` pool.

---

## Features

- **Email & Password Authentication**: Full user signup and signin powered by [Better Auth](https://better-auth.com).
- **Session Verification on the Server**: Every page and server action verifies the session server-side with `auth.api.getSession({ headers: await headers() })`. Client user IDs are never trusted.
- **Boards Management**:
  - Create, edit, and delete boards.
  - Choose between **Private** (strictly shielded, 404 for unauthorized visitors) and **Public** (shareable read-only links).
- **Item Curation**:
  - Add items with an image URL, title, optional link URL, and notes.
  - Responsive **Masonry Grid** layout.
- **Relational Integrity**:
  - Foreign key constraints with `ON DELETE CASCADE` (deleting a board automatically deletes all its items).
  - Indexed on `user_id` and `board_id` for fast queries.
- **Direct PostgreSQL Connection**:
  - Uses `pg.Pool` with connection pooling and SSL support for Supabase.
  - No `@supabase/supabase-js` or Supabase Auth required.

## Getting Started

### 1. Configure Supabase PostgreSQL

Open your Supabase project dashboard, navigate to the **SQL Editor**, and run the SQL commands from:
```bash
schema.sql
```
This script creates:
1. Better Auth tables: `user`, `session`, `account`, and `verification`.
2. Application tables: `boards` and `items` with foreign keys, cascade deletes, and indexes.

### 2. Environment Variables

Your `.env.local` file is already created with a securely generated `BETTER_AUTH_SECRET`:
```env
BETTER_AUTH_SECRET=<auto-generated-32-byte-secret>
BETTER_AUTH_URL=http://localhost:3000
DATABASE_URL=
```

Paste your Supabase Postgres connection string into `DATABASE_URL` in `.env.local`:
```env
DATABASE_URL=postgres://postgres.[YOUR-PROJECT-REF]:[YOUR-PASSWORD]@aws-0-[REGION].pooler.supabase.com:6543/postgres?sslmode=require
```

> **Security Note:** Never commit your `.env.local` file or share your database password.

### 3. Install Dependencies & Run

Install the dependencies:
```bash
npm install
```

Start the development server:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
